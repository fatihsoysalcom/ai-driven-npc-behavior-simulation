# AI Driven NPC Behavior Simulation

This Python script simulates AI-driven Non-Player Character (NPC) behavior in a game engine context. It demonstrates how an NPC's personality traits and environmental perceptions influence its decisions and actions, mimicking a core aspect of modern game AI.

## Language

`python`

## How to Run

Save the code as `ai_npc_simulation.py` and run it from your terminal using: `python ai_npc_simulation.py`
